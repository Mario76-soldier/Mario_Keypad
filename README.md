# Mario_Keypad
This is applicated keypad such as ctrl+c and ctrl+v

## Cloning

This repository uses a git submodule for the key switch footprint library. Clone with:

```sh
git clone --recurse-submodules <this-repo-url>
```

If you already cloned without it:

```sh
git submodule update --init
```
